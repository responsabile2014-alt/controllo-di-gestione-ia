# Controllo di gestione con l'intelligenza artificiale - materiali del libro

Libro di Tania Cilio. Qui si trovano i materiali che accompagnano il libro, tutti costruiti sugli stessi numeri dell'impresa guida.

## Come scaricare tutto

1. In questa pagina premi il pulsante verde **Code**, sopra l'elenco dei file, e scegli **Download ZIP**.
2. Apri il file ZIP scaricato ed estrai la cartella (su Windows: tasto destro sul file, poi «Estrai tutto»; su Mac basta un doppio clic).
3. Lavora sempre sulla cartella estratta, non dentro lo ZIP: contiene la web app, il file Excel, il file Word e la cartella file_esercitazione.

## Da dove partire

1. **La prima richiesta** (capitolo 19, paragrafo 19.2): il testo è nel libro, il file da allegare è nella cartella [file_esercitazione/par_19_2/prima_richiesta](file_esercitazione/par_19_2/prima_richiesta). Leggi il LEGGIMI.txt della cartella: la risposta giusta ritrova 4.812 righe e 820.000 euro.
2. **Poi il lavoro 1** (Classificare i costi): copia dal file Word il Protocollo universale e la Richiesta 1 e allega i quattro file della cartella [file_esercitazione/lavoro_01](file_esercitazione/lavoro_01).

## Come si usano

- **Web app:** si apre direttamente, anche dal telefono, all'indirizzo https://responsabile2014-alt.github.io/controllo-di-gestione-ia/ (non serve scaricare nulla). In alternativa si scarica il file index.html e lo si apre nel browser: funziona anche senza rete.
- **File Excel:** si apre con Excel o con LibreOffice. Si comincia dal foglio «Guida».
- **File Word:** si copia la richiesta che serve, con il Protocollo universale in testa (per le richieste sul bilancio pubblico anche la regola generale e, dove il file lo indica, il testo del collaudo in fondo), e si confronta la risposta con il collaudo.
- **File di esercitazione:** si allegano allo strumento i file della cartella del lavoro; per ricontrollarli, dalla cartella file_esercitazione: `python3 verifica_tutto.py` (su Windows, se il comando python3 non esiste: `python verifica_tutto.py` oppure `py verifica_tutto.py`).

I dati dell'impresa guida e il bilancio di esempio sono costruiti per l'esercitazione e non corrispondono a nessuna società reale.
