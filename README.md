# Controllo di gestione con l'intelligenza artificiale - materiali del libro

Libro di Tania Cilio. Qui si trovano i materiali che accompagnano il libro, tutti costruiti sugli stessi numeri dell'impresa guida.

## I materiali

| Materiale | File | Che cosa contiene |
|---|---|---|
| Web app | [index.html](index.html) | Formule spiegate una per una, esercizi su tre livelli, quiz, mini casi, flashcard, glossario e calcolatori, organizzati nei 20 capitoli del libro. Si apre nel browser, anche dal telefono, senza installazioni. |
| File Excel | [Controllo_di_gestione_IA_Excel.xlsx](Controllo_di_gestione_IA_Excel.xlsx) | Un foglio per capitolo con le formule scritte nelle celle, il confronto con i numeri del libro, gli esercizi con le soluzioni e un bilancio di esempio con numeri inventati. |
| File Word con 30 richieste | [30_Prompt_IA_Controllo_di_gestione.docx](30_Prompt_IA_Controllo_di_gestione.docx) | Le richieste pronte da usare con gli strumenti di intelligenza artificiale: i 15 lavori del capitolo 19, 7 richieste sul bilancio pubblico e 8 richieste nuove, ciascuna con il suo collaudo. |
| File di esercitazione | [file_esercitazione](file_esercitazione/README.md) | I file di dati per provare le richieste del capitolo 19, una cartella per lavoro o esempio, ciascuna con un LEGGIMI.txt e, quando contiene dati, un verifica.py. |

## Come si usano

- **Web app:** si apre il file index.html nel browser. Se il repository è pubblicato con GitHub Pages, la web app si apre direttamente dall'indirizzo del sito.
- **File Excel:** si apre con Excel o con LibreOffice. Si comincia dal foglio «Guida».
- **File Word:** si copia la richiesta che serve, con il Protocollo universale in testa (per le richieste sul bilancio pubblico anche la regola generale e, dove il file lo indica, il testo del collaudo in fondo), e si confronta la risposta con il collaudo.
- **File di esercitazione:** si allegano allo strumento i file della cartella del lavoro; per ricontrollarli, dalla cartella file_esercitazione: `python3 verifica_tutto.py`.

I dati dell'impresa guida e il bilancio di esempio sono costruiti per l'esercitazione e non corrispondono a nessuna società reale.
