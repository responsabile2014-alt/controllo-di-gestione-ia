# File di esercitazione del capitolo 19

Libro: «Controllo di gestione con l'intelligenza artificiale», Tania Cilio.

Sono i file per provare le richieste del capitolo 19 sull'impresa guida del libro e controllare che la risposta dello strumento ritrovi i numeri che il libro stampa. Sono dati di esercitazione, costruiti sui totali del libro: non contengono dati reali.

Le istruzioni complete sono nel file [LEGGIMI.txt](LEGGIMI.txt). Ogni cartella ha il suo LEGGIMI.txt, con il modo d'uso e i numeri da ritrovare nel collaudo, e, quando contiene dati, un verifica.py.

## Verifica dei file

Serve Python 3.7 o successivo, con la sola libreria standard. Dalla cartella che contiene questo file:

```
python3 verifica_tutto.py
```

Il comando esegue i verifica.py di tutte le cartelle e i controlli di coerenza fra le cartelle, e stampa PASS o FAIL per ogni numero e il riepilogo finale.
